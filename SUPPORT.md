# Support

Use GitHub Discussions, if enabled, for setup questions and usage help. Use the issue templates for reproducible bugs and feature proposals.

Before requesting help:

1. Read `README.md` and `docs/DEPLOYMENT.md`.
2. Run `npm ci` and `npm run check` on Node.js 20.19 or later.
3. Confirm required environment variable names without posting their values.
4. Search existing issues.

Never post API keys, tokens, `.env` contents, uploaded student work, database dumps, or production logs containing user data. Report vulnerabilities privately according to `SECURITY.md`.
